A few simple steps

Download.
Open. Create.

  1. Save the HTML file and open it in Edge or Chrome.
  2. Choose an ETF file, a supported SPX file or a Studio project. Check the encoding in the preview.
  3. Edit and save as a .fopproj project.
  4. Choose the FOP export profile and export. Test the output in an abas test environment first.

This is a preview release. SPX 6.5 / TREE 17 is supported. Browser and company policies may restrict file dialogs. Save your project files regularly.
